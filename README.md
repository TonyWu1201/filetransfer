# filetransfer — 局域网文件/文件夹传输工具

点对点文件与文件夹传输工具，支持命令行（CLI）与图形界面（PyQt6 GUI），附带 UDP 广播设备发现。

## 功能

- 发送/接收文件、文件夹（可多选混合，保留目录结构，嵌套多层）
- UDP 广播自动发现局域网内的在线设备（`ft list` 或 GUI 目标主机下拉框）
- 多线程接收，支持同时接受多台机器传输
- 重名文件自动追加序号（如 `a (1).txt`），不会覆盖已有文件
- 实时进度显示（CLI 进度条 / GUI 进度条）
- CLI 纯标准库；GUI 依赖 PyQt6

## 安装

```bash
uv sync
```

## 命令行用法

```bash
# 机器 A：启动接收（默认端口 54546，文件保存在当前目录）
uv run ft receive
uv run ft receive --port 60000 --out D:\received

# 机器 B：发送（--to 可填 IP 或主机名）
uv run ft send .\报告.docx .\图片文件夹 --to 192.168.1.20

# 发送时指定目标端口（--port，默认 54546）
uv run ft send .\报告.docx --to 192.168.1.20 --port 60000

# 扫描局域网在线设备
uv run ft list

# 查看帮助
uv run ft --help
```

## 图形界面

```bash
# 启动 GUI（或直接 uv run python main.py）
uv run ft-gui
```

- **发送页**：添加文件/文件夹 → 从下拉框选择目标主机（自动扫描，也可手输 IP）→ 点击发送
- **接收页**：设置端口与保存目录 → 启动接收；勾选“自动接受所有传输”或对每个请求手动接受/拒绝

## 安全说明

传输不加密、无鉴权，仅适用于可信局域网环境。接收方数据落盘前会做路径校验，阻止 `../` 路径穿越。

## 常见问题

- **连接被拒绝**：确认对方已启动接收服务或 GUI 的接收页；检查防火墙是否放行 Python 与所用端口（首次运行 Windows 会弹窗询问，请允许专用网络）。
- **发现不到设备**：UDP 广播无法跨越路由器/不同子网（如跨 VLAN、VPN、多网卡默认路由走 VPN 时）。可改用 `ft send ... --to <对方IP>` 手动指定；或在 GUI 目标主机框输入对方 IP 后点击“刷新设备列表”，或 `ft list --host <对方IP>`，对已知主机做可跨路由的单播探测。同时检查防火墙是否放行 UDP 54545（发现）与 TCP 54546（传输）。
- **开发/测试**：`uv run pytest`
